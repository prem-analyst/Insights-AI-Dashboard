# 📊 Insights AI Dashboard

An interactive Business Intelligence Dashboard built using **Python**, **Streamlit**, **Pandas**, and **Plotly** for analyzing Superstore Sales data.

---

## 🚀 Features

- 📈 KPI Metrics Dashboard
- 📊 Interactive Sales by Category Chart
- 🥧 Sales Distribution (Donut Chart)
- 🏙️ Top 10 Cities by Sales
- 💰 Top 10 Cities by Profit
- 🔍 Region & Category Filters
- 📥 Download Filtered Data
- 📌 Business Insights & Recommendations
- 🎨 Custom Dashboard Theme

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
